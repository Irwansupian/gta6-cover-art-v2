Vice Panel Studio — a multi-panel GTA-style cover art maker. Drop in your own photos, cast them across six poster layouts, grade them with five per-pixel colour grades (Sunset, Neon Nights, Golden Hour, Vice Pastel, Noir), finish with film grain, vignette or halftone, set a bold Anton title with a Pacifico script subtitle, and export a shareable PNG at 1080×1080, 1080×1350 or 1920×1080. Fully offline; no Rockstar artwork, logos or fonts — type is Anton and Pacifico under the SIL Open Font License.

## Run it

```sh
node serve.ts
```

Then open the local address it prints in your browser.
